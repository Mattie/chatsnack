# Upgrading Samplers to 0.10.0

Samplers without an explicit provider or Jev model now use OpenAI Decisions with
`gpt-6-luna` and `OPENAI_API_KEY`. This also applies to saved YAML.

To keep an existing Sampler on Jev, add:

```yaml
params:
  provider: typesafe
```

Keep `TYPESAFE_API_KEY` configured. `model="jev-latest"` also selects TypeSafe.
If switching backends, recalibrate any confidence thresholds.

Other compatibility changes:

- OpenAI can refuse individual questions. Check `answer.refused` before using
  answer values, which are `None` on refusal.
- `Sampler.compile()` returns the selected provider's wire format.
  `Question.compile()` is unchanged.
- `Sample.to_dict()` adds provider, params, image references, and refusal flags.
- `provider`, `images`, and `fillings` are reserved call keywords. Pass template
  variables with those names through `fillings={...}`.
- TypeSafe-specific retry options require `provider="typesafe"`. OpenAI supports
  `timeout` and `retry.max_retries`.

See the [Sampler guide](../guides/samplers.md) for images and replay, and the
[API reference](../reference/api/sampler.md) for execution settings.
