# Upgrading Samplers to 0.10.0

Provider-less Samplers now use OpenAI Decisions with `gpt-6-luna`. This includes
previously saved YAML. Set `OPENAI_API_KEY` for the new default. To keep an existing
Jev application on its backend, author `model="jev-latest"` or `provider="typesafe"`
and keep `TYPESAFE_API_KEY` configured:

```yaml
params:
  provider: typesafe
```

Explicit providers win over inferred routing. Authored model values pass through
unchanged. `TYPESAFE_DEFAULT_MODEL` applies only to TypeSafe. There is no fallback.

`Sampler.compile()` now shows an OpenAI request by default (`input` and a questions
array). Select TypeSafe to inspect the previous `state` and questions map.
`Question.compile()` is unchanged.

Successful answers retain the same views. Guard `.refused` before using nullable
values: a refused question has `None` for choice, score, probabilities, confidence,
yes, and no. Refusals occupy their original slots, so `.answer` can be refused.
Transport errors remain exceptions.

Calibrate application confidence thresholds again when switching backends. As
verified on 2026-10-06, published input prices are $0.10/million tokens for Decisions
and $0.042 for Jev; accounting and applicable premiums differ. See the
[Decisions guide](https://developers.openai.com/api/docs/guides/decisions) and
[Jev models](https://docs.typesafe.ai/models).

OpenAI accepts `timeout` and `retry.max_retries`. Other existing TypeSafe retry
options, such as `backoff_initial`, require explicit TypeSafe selection. Unsupported
OpenAI retry settings raise before dependencies or this Sampler run.

New reserved query/compile keywords are `provider`, `images`, and `fillings`. Use
the explicit mapping for template variables with these or earlier reserved names
(`question`, `questions`, `data`, `model`, `timeout`, `retry`, `base_url`, `api_key_env`):

```python
sampler.ask("Good?", fillings={"provider": "our bakery", "images": "a word"})
```

Ordinary keyword fillings still work. Binding the same variable in both forms
raises an ambiguity error.

`Sample.to_dict()` adds provider, nonsecret params, captured image references, and
refusal flags. Consumers validating its schema must allow these members. Existing
positional Sample construction still works.

Saved image paths remain live. Evaluated Sample images are snapshots; replay YAML
refers to the assets stash, so preserve that directory when moving a replay.
Follow-up Samplers inherit previous Sample images automatically. `images=[]` clears
them and survives save/load.

Jev images use the same `images=` surface as OpenAI. The adapter infers the image
header from resolved image input; no image opt-in is needed. Use `images=[]` to
clear attached images. Larger Jev inputs also need no flag: after an explicit
HTTP 400 `max_tokens_exceeded`, chatsnack retries the same resolved request once
with extended context. Short requests and unrelated errors stay unchanged.
The unreleased `experimental` parameter has been removed entirely; delete it
from saved params. `experimental` is again available as an ordinary filling name.
TypeSafe SDK now requires
`>=0.7.5,<0.8.0`; its response objects use Pydantic instead of msgspec.
Jev accepts PNG/JPEG with its own image limits, rather than OpenAI's WebP and
128-image contract. See the [API reference](../reference/api/sampler.md#images-and-fillings).

The bundled TypeSafe web examples explicitly select their existing backend.
0.10.0 is this compatibility boundary; publication requires a separate request.
